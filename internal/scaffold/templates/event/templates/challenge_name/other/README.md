# Private — author-only

Files in this folder are **never** distributed to players or built into the challenge image.

Use this for:
- Flag generators / scripts that produce per-event flag values
- Research notes, ideas, draft variants
- Decoy assets you considered but didn't ship

Anything you put under `assets/` (zipped or otherwise) is uploaded to the platform as a downloadable handout. Anything under `challenge/src/` is copied into the container image. **Use `other/` for anything that's neither.**
